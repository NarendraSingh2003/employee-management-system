# Employee Management System

A web-based Employee Management System developed using PHP and MySQL. This project helps manage employee records efficiently with features like employee registration, updating employee details, deleting records, and viewing employee information through an admin dashboard.

## 🚀 Features

* Admin Login Authentication
* Add Employee
* View Employee List
* Edit Employee Details
* Delete Employee Records
* Dashboard Overview
* MySQL Database Integration
* Responsive User Interface

## 🛠️ Technologies Used

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* XAMPP
* Git & GitHub

## ⚙️ Installation Steps

1. Install XAMPP
2. Start Apache and MySQL
3. Copy project folder into:

   ```
   htdocs/
   ```
4. Open phpMyAdmin
5. Create database:

   ```
   employee_management
   ```
6. Import:

   ```
   database.sql
   ```
7. Run project:

   ```
   http://localhost/employee-management-system
   ```
